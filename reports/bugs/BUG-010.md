# BUG-010: /robots.txt и /sitemap.xml отдают HTML-страницу с HTTP 200 (SEO-поверхность сломана)

| Поле | Значение |
|------|----------|
| ID | BUG-010 |
| Область | 12. SEO / 13. Производительность (краулинг) |
| Severity | Low |
| Priority | P3 |
| Слой | UI (сборка storefront) |
| Окружение | sandbox-session-cand-c26fa443df2a4d52ba4c0f61ea385fac.fly.dev, Next.js storefront, 28.09.2026 |
| Воспроизводимость | всегда |
| Статус | Confirmed (контур Б) |

## Шаги воспроизведения

1. `GET /robots.txt` → HTTP **200**, `content-type: text/html`, ~31 КБ HTML
2. `GET /sitemap.xml` → HTTP **200**, `content-type: text/html`, ~31 КБ HTML

## Фактический результат

Оба «SEO-файла» — это HTML-страницы (в RSC-полезной нагрузке видно `Page not found`,
роут отработал как not-found с кодом 200). Краулер получает бессмысленный HTML вместо
`User-agent:` директив и XML-карты сайта.

## Ожидаемый результат

`/robots.txt` — текст (`text/plain`), `/sitemap.xml` — XML (`application/xml` или
`text/xml`). Основание: конвенция SEO (RFC-практика robots.txt, протокол sitemaps.org);
в R-012 ожидались «существующие и валидные» — уточняется: они не валидны.

## Влияние

Краулинг поисковиками не управляется; индексация неоптимальна. Для sandbox-демо некритично.

## Артефакты

- `reports/artifacts/nfr-seo-robots_txt.json`, `nfr-seo-sitemap_xml.json`
- Воспроизведение: `npx tsx scripts/ts/nfr-headers.ts` (секция SEO)

## Примечания

- Статус R-012 в реестре: «нарушено» (уточнение основания: 200 ≠ валидность).
- Связано с классом BUG-008: маршруты/артефакты сборки, ожидающие данных от бэкенда,
  деградируют молча (200 вместо явной ошибки).
