# BUG-014: Радиогруппа «Manual Payment» на address-шаге — обе опции aria-checked=true

| Поле | Значение |
|------|----------|
| ID | BUG-014 |
| Область | 12. Доступность / 11. UI-состояния |
| Severity | Low |

| Воспроизводимость | всегда (в пределах сессии с корзиной) |
| Статус | Confirmed (контур Б, DOM-снимок) |

## Шаги воспроизведения

1. Корзина с товаром → `?step=address`.
2. В блоке «Manual Payment» кликнуть любую radio-опцию.
3. Прочитать `aria-checked` обеих опций.

## Ожидаемый результат

Ровно одна опция radiogroup имеет `aria-checked="true"`. Основание: WAI-ARIA (radiogroup —
единичный выбор); согласованность с axe-правилом (класс nested-interactive/radio в BUG-012).

## Фактический результат

После клика **обе** опции отдают `aria-checked="true"`:
`["true", "true"]` (`probe-radiogroup.json`, afterClick).

## Влияние

Скринридер оглашает оба способа оплаты выбранными; визуальное и семантическое состояние
расходятся. Функционально выбор не блокирует (клик регистрируется).

## Артефакты

- `reports/artifacts/regress-2909/probe-radiogroup.png`
